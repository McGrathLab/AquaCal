Implementation details:

**Input validation (upfront, before optimization):**
- Raise `ValueError` if `correspondences` is empty
- Filter out zero-weight correspondences silently (soft-disable pattern)
- Raise `ValueError` if any correspondence has `weight < 0`
- Raise `ValueError` if any correspondence has fewer than 2 observations
- Raise `ValueError` if any observation references a camera name not in `result.cameras`
- Raise `InsufficientDataError` if fewer than 10 correspondences remain after filtering zeros (Claude's discretion: 10 is reasonable minimum)
- Validate point_3d is shape (3,) and observations values are shape (2,) — raise ValueError on bad shapes

**Parameter packing (custom for point correspondences — NO board poses):**
Write local `_pack_refine_params` and `_unpack_refine_params` functions (do NOT modify `_optim_common.py` — its pack/unpack are board-pose-specific). Parameter layout:
- For each non-reference camera (sorted order, skip reference): rvec (3), tvec (3)
- water_z (1): single shared parameter

Reference camera = first camera in sorted `result.cameras` keys (same convention as existing pipeline — reference camera is at world origin with identity R and zero t).

**Cost function (`_compute_point_residuals`):**
For each correspondence, for each observation (camera_name, pixel):
1. Build Camera and Interface objects for that camera
2. Call `refractive_project_batch(camera, interface, point_3d.reshape(1, 3))`
3. Compute residual = (projected - observed) * sqrt(weight)
4. If projection returns NaN, use penalty of 100px (same pattern as `_optim_common.compute_residuals`)
Return flat array of all residuals [r0_x, r0_y, r1_x, r1_y, ...]

**Jacobian sparsity (`_build_point_jac_sparsity`):**
Build sparsity pattern. Each (correspondence, camera) residual pair depends on:
- That camera's extrinsic params (6, or 0 if reference camera)
- water_z (1) — dense column, ALL residuals depend on it

Use `make_sparse_jacobian_func` from `_optim_common.py` for the sparse Jacobian callable (reuse the battle-tested pattern).

**Bounds:**
- Extrinsics: unbounded (-inf, inf)
- water_z: [0.01, 2.0] (same as existing pipeline)

**Optimization:**
Use `scipy.optimize.least_squares` with method="trf", no loss function (Phase 14 adds robust loss). Pass sparse Jacobian callable.

**Non-convergence handling (per user decision):**
- If `result.status <= 0`: log warning via `logging.getLogger(__name__).warning(...)`, but still return the best result found. Add a `convergence_info` dict to the returned `CalibrationResult.metadata` as a new optional field — actually, CalibrationMetadata is a fixed dataclass. Instead, use a simpler approach: add a module-level `RefinementStatus` enum or just log and return. Per user decision "provide programmatic way for caller to detect non-convergence", add a `convergence_status` attribute to the returned CalibrationResult's metadata. Since CalibrationMetadata is a frozen schema, the cleanest approach: raise a WARNING via logging and set the returned CalibrationResult's diagnostics.reprojection_error_rms to the final RMS. The caller can compare before/after RMS. For Phase 13 (returns CalibrationResult directly), this is sufficient. Phase 15 wraps in RefinementResult with explicit status.

Actually, the simplest approach that satisfies "programmatic detection": if status <= 0, log a warning. The caller can compare result before/after. If they need explicit status, Phase 15's RefinementResult will provide it. For Phase 13, just log the warning and return best-effort result. Do NOT raise ConvergenceError (user decision says "return best result found").

**Building the returned CalibrationResult:**
1. Unpack optimized params into extrinsics and water_z
2. Build new CameraCalibration objects with updated extrinsics and water_z, keeping intrinsics unchanged
3. Copy interface, board, metadata from input result
4. Compute new diagnostics: set reprojection_error_rms to final RMS from optimization, clear per_corner fields (not applicable), set validation fields to 0.0 (Phase 15 adds real validation)
5. Return new CalibrationResult
