  <name>Task 1: Extend refine_calibration signature and refactor pack/unpack/sparsity/bounds for intrinsics + tilt</name>
  <files>src/aquacal/calibration/point_refinement.py</files>
  <action>
Refactor the local _pack_refine_params, _unpack_refine_params, _build_point_jac_sparsity functions and the bounds logic in refine_calibration() to support intrinsics refinement and reference camera tilt. The key challenge is that _optim_common.py's pack_params/unpack_params require board_poses and frame_order (board-based), which point refinement doesn't have. Two approaches:

**Approach A (preferred — per CONTEXT.md "code reuse strategy"):** Refactor the local _pack/_unpack/_sparsity/_bounds functions to support the new parameters directly, mirroring the parameter layout from _optim_common but without the board pose block. This keeps point_refinement.py self-contained while following the same conventions.

Parameter layout for the extended version:
- If not normal_fixed: reference camera tilt rx, ry (2)
- For each non-reference camera: rvec (3), tvec (3)
- water_z (1)
- If refine_intrinsics, for each camera in camera_order: fx (1), fy (1), cx (1), cy (1)

Specific changes to `_pack_refine_params`:
- Add parameters: `intrinsics: dict[str, CameraIntrinsics] | None = None`, `refine_intrinsics: bool = False`, `normal_fixed: bool = True`
- When not normal_fixed, prepend 2 tilt params (rx, ry from reference camera rvec[:2])
- When refine_intrinsics, append fx/fy/cx/cy for each camera in camera_order

Specific changes to `_unpack_refine_params`:
- Add parameters: `camera_order: list[str]`, `base_intrinsics: dict[str, CameraIntrinsics] | None = None`, `refine_intrinsics: bool = False`, `normal_fixed: bool = True`
- When not normal_fixed, extract tilt rx/ry from first 2 params, construct reference R from [rx, ry, 0], set ref t to zeros
- When refine_intrinsics, extract fx/fy/cx/cy per camera, build CameraIntrinsics copying dist_coeffs and image_size from base
- Return tuple extended to include intrinsics dict

Specific changes to `_build_point_jac_sparsity`:
- Add parameters: `refine_intrinsics: bool = False`, `normal_fixed: bool = True`
- When not normal_fixed, add 2 tilt columns at start; reference camera residuals depend on them
- When refine_intrinsics, add 4 columns per camera at end; each camera's residuals depend on its own intrinsic block
- water_z column index shifts by n_tilt_params

Create new `_build_point_bounds` function:
- Parameters: camera_order, reference_camera, base_intrinsics, refine_intrinsics, normal_fixed, intrinsics_bound_pct
- Tilt bounds: [-0.2, 0.2] radians (matching _optim_common)
- Water_z bounds: [0.01, 2.0] meters (existing)
- Intrinsic bounds: each of fx/fy/cx/cy bounded within +/- intrinsics_bound_pct of initial value

Update `refine_calibration` signature to add new keyword arguments:
```python
def refine_calibration(
    result: CalibrationResult,
    correspondences: list[PointCorrespondence],
    *,
    refine_intrinsics: bool = False,
    intrinsics_bound_pct: float = 0.1,
    normal_fixed: bool = True,
    loss: str = "linear",
    f_scale: float = 1.0,
    verbose: bool = False,
    ftol: float = 1e-8,
    xtol: float = 1e-8,
    max_nfev: int | None = None,
) -> CalibrationResult:
```

In the function body:
1. Validate `loss` parameter: must be one of "linear", "huber", "cauchy". Raise ValueError otherwise.
2. Pass `refine_intrinsics`, `normal_fixed`, `intrinsics_bound_pct` to the updated local helpers for packing, unpacking, sparsity, and bounds.
3. Pass `loss=loss` and `f_scale=f_scale` directly to `scipy.optimize.least_squares` (scipy handles them natively).
4. When `refine_intrinsics=True` and `max_nfev is None`, auto-scale: set max_nfev to `200 * n_params` (more params need more iterations).
5. Update `_compute_point_residuals` to accept and use the new parameters (intrinsics from params when refining, from base when not).
6. When `loss != 'linear'`, compute RMS from raw (unweighted by loss) residuals by re-evaluating `_compute_point_residuals` at the final params, not from `opt_result.fun` (which contains loss-transformed values). Actually, scipy's `opt_result.fun` returns the raw residual vector f(x) regardless of loss setting — only the cost function J(x) uses the loss internally. So `opt_result.fun` is fine for RMS computation.

After optimization, when `refine_intrinsics=True`:
- Extract the refined intrinsics from unpacked params
- Log a warning for any camera where any of fx/fy/cx/cy shifted more than 5% from initial
- Store initial intrinsics in metadata for before/after comparison
- Use refined intrinsics in output CameraCalibration objects

When `normal_fixed=False`:
- Extract the refined reference camera extrinsics from unpacked params
- Use them in output CameraCalibration for the reference camera

Record active extensions in output metadata:
- Add to metadata dict (or as a new field): refine_intrinsics (bool), loss (str), f_scale (float)
- CalibrationMetadata is a frozen dataclass — use copy.copy and set metadata on the output CalibrationResult. If CalibrationMetadata doesn't support arbitrary extra fields, store in a comment or skip metadata recording for now (Claude's discretion on exact approach).

Update the module docstring to mention intrinsics refinement and robust loss.
