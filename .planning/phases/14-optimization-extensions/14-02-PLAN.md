  <action>
Add a new test class `TestIntrinsicsRefinement` to test_point_refinement.py with the following tests. Use the existing `calibration_result`, `synthetic_correspondences`, and `perturbed_result` fixtures.

**Input validation tests (fast, no @pytest.mark.slow):**

1. `test_invalid_loss_value` — Passing `loss='softl1'` or any invalid string raises ValueError. Test with the `calibration_result` and `synthetic_correspondences` fixtures.

2. `test_valid_loss_values_accepted` — Passing `loss='linear'`, `loss='huber'`, and `loss='cauchy'` all run without error (use the real fixtures, but can use `max_nfev=1` to short-circuit the optimization — just proving the parameter is accepted).

**Intrinsics refinement tests (@pytest.mark.slow):**

3. `test_intrinsics_change_when_enabled` — Create a `perturbed_result` with slightly wrong intrinsics (shift fx by +20 pixels on cam1, fy by -15 on cam2). Generate synthetic correspondences from the ORIGINAL (correct) intrinsics. Call `refine_calibration(perturbed_result, correspondences, refine_intrinsics=True)`. Assert that the refined intrinsics for cam1 and cam2 have moved TOWARD the original values (i.e., the error in fx/fy decreased).

4. `test_intrinsics_fixed_when_disabled` — Call `refine_calibration(perturbed_result, correspondences, refine_intrinsics=False)`. Assert intrinsics are EXACTLY equal to input intrinsics (np.array_equal on K matrices). This uses the standard perturbed_result fixture (only extrinsics perturbed, intrinsics already correct).

5. `test_intrinsics_bound_pct_limits_drift` — Call with `refine_intrinsics=True, intrinsics_bound_pct=0.02` (tight 2% bound). Verify that all refined intrinsics are within 2% of their initial values. Compare each of fx/fy/cx/cy against initial ± 2%.

**Reference camera tilt test (@pytest.mark.slow):**

6. `test_normal_fixed_false_allows_tilt` — Create a calibration where the reference camera has a small tilt (rx=0.02, ry=0.01). Generate correspondences from this tilted setup. Create a perturbed version with the reference camera at identity (no tilt). Call `refine_calibration(perturbed, correspondences, normal_fixed=False)`. Assert the reference camera's R matrix has changed from identity (i.e., tilt was optimized). Assert RMS decreased.

  <action>
Add a new test class `TestRobustLoss` to test_point_refinement.py with the following tests. All are @pytest.mark.slow since they run optimizations.

**Setup for outlier tests:**
Create a helper fixture or inline setup that takes the `synthetic_correspondences` and adds 3-5 "outlier" correspondences — these have correct point_3d values but pixel observations shifted by 50-100 pixels (simulating detection errors). Use this "contaminated" set for the loss comparison tests.

1. `test_huber_reduces_outlier_influence` — Run refine_calibration twice on the contaminated correspondences with perturbed_result:
   - Once with `loss='linear'` (default squared loss)
   - Once with `loss='huber', f_scale=2.0`

   Compare the RMS on the CLEAN (non-outlier) correspondences. The Huber result should have lower RMS on clean points, because the outliers pulled the linear solution more. Use `_compute_reprojection_rms` with only the clean subset to measure this.

2. `test_cauchy_reduces_outlier_influence` — Same as above but with `loss='cauchy', f_scale=2.0`. Cauchy result should have lower clean-subset RMS than linear.

3. `test_linear_loss_matches_default` — Run `refine_calibration(perturbed_result, correspondences, loss='linear')` and compare with `refine_calibration(perturbed_result, correspondences)`. The results should be identical (same RMS, same extrinsics). This proves `loss='linear'` is truly the default.

4. `test_combined_intrinsics_and_robust_loss` — Run with both `refine_intrinsics=True` and `loss='huber'` on perturbed data. Assert that it completes without error and that both intrinsics changed AND RMS decreased. This proves the extensions compose correctly.
