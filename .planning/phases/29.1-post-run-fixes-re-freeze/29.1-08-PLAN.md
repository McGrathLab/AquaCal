## Hard constraints (all plans)

1. **`src/` must not be modified.** `git diff --stat rerun-freeze-01..HEAD -- src/` prints nothing.
2. **The new tag must not match the version pattern the publish workflow triggers on.**
   `rerun-freeze-02` is the decided name (D-12). This is the phase's one-way door: a pushed
   tag matching that pattern fires the publish workflow and ships a release to PyPI, which
   cannot be un-published, only yanked.
3. **`rerun-freeze-01` never moves.** A force-moved tag destroys the record of the previous
   attempt, which is precisely the provenance fracture this milestone exists to stop repeating.
   A second tag is a normal outcome, not a failure signal.
4. **Push the branch and the one tag by explicit name.** Never push all tags at once.
5. **The driver exits non-zero on a healthy run** — acceptance is the roll-up, never `$?`.
6. **Do not add pre-flight override flags**, and do not patch a verification clone in place and
   continue. A stage that ran at a different commit than the rest makes a run unreportable.
