## Decisions Made

- **D-04 by removal, not by adding a writer.** The design table in `2026-08-15-suspend-programmatic-check-for-reshaped-artifacts.md` carries `--seeds` rows for E5 and E7 and deliberately none for E1, and `_run_band`'s code and docstring already matched it. Adding a `write_degeneracy_breakdown` call site would have amended the design from the manifest side, silently. The manifests were the outlier and the manifests moved.
- **D-07 resolved in favour of the `:1209` comment.** The comment, the manifest and the band sidecar's own reason for existing all say band mode does not own those records; only the docstring and the call site dissented, and the docstring was written to describe the call site. The chosen form — *may create, never overwrite, enforced at the call* — is the one that leaves every reading true, including the standalone-band-into-a-fresh-`--out` case that must still produce the records.
- **D-08 fixed as a class, not an instance.** The todo asked for "update the literal to say four seeds and 256/384 rows". That was not the fix taken. D-10's point is that three stale rationales surfaced in a single day, each a claim outliving its conditions; re-freezing a *correct* number into the same literal buys exactly one grid resize before the defect returns. The field is computed instead, and only the cross-reference to ruling A1 and the four genuinely-static claims remain fixed text.
- **Tests build their expected values from the module's own constants.** `TestBandScopeIsDerived` reads `e1.NOISE_LEVELS` and `e1.TEST_DEPTHS` and re-reads the emitted CSVs rather than hardcoding `4` or `256`. A test that froze those numbers into itself would be the same defect one level up. (The single exception is deliberate: one assertion pins `(256, 384)` explicitly, as ruling A1's arithmetic *checked* rather than trusted.)
- **The retired claim is named, not scrubbed.** The docstring keeps the ten-seed / 640-960-row figures under an explicit "the version that did … from the pre-A1 plan" attribution — the same retention `test_stale_provenance_strings.py` already pins for `e2_real_rig.py`'s site 4. A version with them deleted destroys the trail that explains the correction.
- **E7 is filed, not fixed.** It carries the identical call and the identical docstring claim. It surfaced by reading, not by a failing gate, and the phase's scope was fixed before it was found. The todo names the asymmetry and E1's resolution; E1's comment names the asymmetry and points at the todo, so it is discoverable from either side.
