## Decisions Made

- **The enumeration command was widened after it was caught hiding a defect.** The first version pre-filtered candidate lines to those containing `#`, `"` or `'` — on the reasoning that only prose carries a stale claim. It yielded 118 lines. But a *wrapped docstring line* has none of those characters, and `e1:43` (`x 2 models = 160 rows at production scale)`) is exactly that. It was found by eye while verifying a neighbouring row. The filter was removed, every count in the audit was restated at the wider command, and the rejection is recorded in the audit's own Enumeration section. **A boundary with a blind spot is not a boundary**, and the narrower command's tidier 118 would have been worth less than the honest 196.
- **Two out-of-boundary twins were corrected, not merely recorded.** Hard constraint 5 says not to widen the *sweep*, and the sweep did not widen — Pass A and Pass B cover only the 11 files. But the planner's stated reason for excluding the shared helpers is that they "carry mechanism, not measured values", and `_expectations.py:23` carries `E1's band is 160/240 rows in the committed tree` — the verbatim twin of an in-boundary defect. Correcting one and leaving the other is the exact partial-fix shape `test_stale_provenance_strings.py` was created to catch. Recorded as a Rule 2 deviation, in its own audit section, and pinned by the same gate.
- **`check_rerun_gates.py:673`'s remedy is deletion of the rate, not attribution.** The plan's two remedies are "name the derivation" and "carry attribution", and the first is preferred wherever the code has the value in hand. That message already interpolates each exempt row's own count, so the frozen `0.268% of 73,975` was pure decoration on a line that prints live data. It is gone; the threshold reference stays.
- **MF-12's digits are retained, not updated.** Writing `-18.8593` in place of `-18.8547` reproduces the defect exactly one run later — the trap the 2026-08-15 pass had to be blocked from, and the reason FIX-06's own remedy asserts `"0.8240" not in source`. The digits stay under an explicit MF-12 attribution, and the docstring now says where to read the current values.
- **The gate's forbidden fragments were chosen against the corrected text as well as the stale text.** `e4`'s clause is `re-run reports the same count` and not `report the same count`, because the correction deliberately contains *"It does NOT report the same count"*. A gate that fails against a perfect fix gets deleted by the next person, which is the tampering path `T-29.1-09` names.
- **`.planning/` was recorded, not edited.** MF-12's decomposition table and MF-16's regenerability claim carry the same stale figures. A manuscript finding is *supposed* to record what was measured when it was written; what it needs is a dated re-measurement note in a manuscript session. Logged to `deferred-items.md`.

The gate asserts on the *sentences it knows about*, and the six survivors are arithmetic and cross-references rather than provenance prose.
