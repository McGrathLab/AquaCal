## Deviations from Plan

### 1. [Rule 3 — Blocking] `.pre-commit-config.yaml`'s detect-secrets exclude also names the moved trees

**Found during:** Task 2, running the hook set against the staged move.

**Issue:** the exclude regex `^(...|experiments/(pre_rerun_baseline/)?results[^/]*/.*|...)$` covers only the *first* archive. With the rename staged, detect-secrets **failed**, reporting Hex High Entropy String findings across the `e6_configs` records — `git_sha` and `config_hash` fields that were already committed and already excluded at the old path. The hook's own comment had predicted exactly this for the Phase 26 move: *"Without it the pure-rename commit trips the hook on ~200 `git_sha` and `config_hash` fields that were already committed and already excluded."*

**Fix:** widened the optional segment to `(pre_rerun_baseline/|freeze01_run_output/)?` and rewrote the comment to name both archives, each with its own purge owner. Re-measured: **Passed**, and Passed again against the committed range.

**Why it is a deviation and not scope creep:** the plan's rule was *mirror every rule naming a moved tree*; it named `.gitignore` because that is where the author knew such rules lived. This is the same rule in a second file, and without it the move commit could not pass its own hooks. `.pre-commit-config.yaml` was not in `files_modified`.

**Commit:** `24bf414`.

### 2. [Rule 1 — Bug] `tests/unit/test_expectations.py` resolved a predicate source against the moved tree

**Found during:** Task 3, running the plan's own verify.

**Issue:** `TestConditionalArtifacts::test_the_committed_conditions_resolve_to_files_that_exist` (written by plan 29.1-09) resolved both conditional predicate sources against a hardcoded `REPO_ROOT / "experiments" / "results"`. Emptying that tree failed it on `experiments/results/benchmark.json`. This is precisely the "any test fixture pointing at a moved tree" class the archive todo's audit clause names.

**Fix:** it now resolves live-first, then the freeze01 archive; names the resolved subject in every assertion (the reason `resolve_results_dir` returns its `which`); and **skips, naming both trees it searched**, when neither holds a run — which is the state of a fresh clone of the tag before the suite runs, where a silent pass would be worth nothing.

It falls back to `freeze01_run_output/` and deliberately **not** to `pre_rerun_baseline/`: its subject is the two conditional artifacts, which only the 2026-08-20 run produced. `pre_rerun_baseline/` predates the condition mechanism entirely, so falling back there would assert against a tree that could not satisfy the claim under any correct manifest.

Confirmed non-vacuous — both sources resolve inside the archive:

    degenerate_observations.csv  -> freeze01_run_output/results/benchmark.json                                  exists=True
    all_observation_depths.csv   -> freeze01_run_output/results_e2_invocations/config_e2_classification.yaml    exists=True

`tests/unit/test_expectations.py` was not in `files_modified`.

**Commit:** `63d3cb5`.

### 3. [Process] The task-2 `git add` silently failed and the commit was amended

`git add` was called with a path list that included the six now-empty directories. Git rejects the whole invocation when a pathspec matches nothing, so **nothing from that call was staged** — the 227 renames were in the index only because `git mv` had put them there, and `.gitignore` was left out of the move commit. Caught by running the plan's own verify, whose `git status --porcelain` clause failed.

Repaired by `git commit --amend` on the unpushed tip rather than by a follow-up commit, deliberately: a follow-up would have left a commit in history in which ~272 ignored files were momentarily un-mirrored, which is the exact state the plan's sequencing exists to prevent. Final commit `24bf414` contains 227 `R100` + `.gitignore` + `.pre-commit-config.yaml`.

The hook results taken before the amend remain valid: `check-added-large-files` inspects *staged* files, and the ignored bulk was never staged because the working-tree `.gitignore` already carried the mirrors.
