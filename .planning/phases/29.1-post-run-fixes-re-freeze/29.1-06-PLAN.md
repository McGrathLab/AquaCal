<objective>
Record the phase's before/after gate result while it is still checkable, then move the
2026-08-20 run's output aside so the tag this phase cuts ships with an empty output tree, and
reconcile every reference to the moved paths.

Purpose: `rerun-freeze-01` was cut from a branch where `experiments/results/` held zero
tracked files. This branch holds 147. A fresh clone of a tag cut as-is would start with a
populated output tree, which (a) makes the driver's pre-flight refuse, (b) destroys the
verifier's strongest invariant — everything under `experiments/results/` was produced by this
run — and (c) re-arms E4's cross-machine pairing hazard, whose worst case can only occur while
a stale record sits at the default path. This is the folded archive-stale-outputs todo's Phase
1, and it is a hard prerequisite for the re-freeze.

Output: a recorded before/after, one archive directory, mirrored ignore rules, and a clean
reference audit.
</objective>
