<objective>
Close the two driver defects that would each cost the 15–16 h run outright.

**D-09/D-10** — `_preflight_frameset` builds `present` with `p.is_file()`. The target holds an
IMAGE set (D-08), so every path is a directory, `present` is empty, the probe exits 2 = ABSENT,
and the driver refuses with *"use `--skip-e2`"* — which would make the entire re-run
**synthetic-only**. This is the criterion-4 class exactly: found before the freeze, fixed inside it.

**D-22** — `is_stage_complete` matches a completion line and ignores the exit-code column, so a
crashed-then-resumed run silently drops a stage that ran AND FAILED. The frozen run's own state
file already contains the proof: `reconstruction_bootstrap  10  complete  ...  1`.

Purpose: make pre-flight able to see the real data, and make resume safe.
Output: two surgical edits to the driver, each with a dry-run test.
</objective>

  <action>
In the embedded Python heredoc, replace exactly two expressions:

  - `present = [p for p in paths if p.is_file()]` → membership by `p.exists()`, so a directory
    counts as present.
  - `total_bytes = sum(p.stat().st_size for p in present)` → a per-path size that recurses when
    the path is a directory (sum `f.stat().st_size` over `p.rglob("*")` for regular files) and
    falls back to `p.stat().st_size` for a file. A directory's own `st_size` is meaningless and
    must never be summed.

`min_total_bytes` read coming from the manifest — never a shell or Python literal (that is how

explicit: § D cut three, do not add a fourth).

Update the function's header comment to state that the check is path-kind agnostic and why: the
target holds an image set, and `detection.py` already auto-selects `ImageSet` for a directory.

Add the tests to `tests/unit/test_run_experiment_suite_dryrun.py` in `TestPreflight`
(`:568-618`), which already covers the refusal-names-its-flag rule. Build the fixtures with
