<objective>
Cut the freeze.

**D-01** — push `experiments/full-suite-rerun` to `origin` plus an annotated tag, so the target
can `git clone --branch <tag>`. A real clone is what makes criterion 2's "clean checkout"
meaningful and keeps `.git` present, which the driver needs for `FROZEN_SHA`, the sha-derived
state-file path, `git describe --tags --long --dirty` in the run manifest (P26-D-45), and Gate
3's cross-artifact sha assertion.

**D-02** — the tag MUST NOT match `v*`. `.github/workflows/publish.yml` triggers on
`push: tags: ['v*']` and publishes to PyPI. `release.yml` triggers on `push: branches: [main]`;
`test.yml` on push-to-main or PR-to-main. Pushing this branch plus a non-`v*` tag therefore fires
**no workflow at all**. Name shape: `rerun-freeze-NN`.

**D-03** — new tag per freeze attempt; tags are never moved. A force-moved tag would destroy the
record of a failed attempt — the same shape as audit finding **F-002** (two commits sharing
"1.8.0"), which this milestone exists to stop repeating.

Purpose: designate the single sha (criterion 1).
Output: `rerun-freeze-01` on origin, and an in-repo record of what it names.
</objective>
