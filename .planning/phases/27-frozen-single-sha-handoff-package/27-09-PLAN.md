<objective>
ROADMAP criterion 3: **environment requirements are written down for the receiving machine** —
and criterion 4: the package requires no further code edits once transferred.

This note is what the Linux machine reads. It goes inside the frozen sha (that is why it is
wave 2, before the tag), and it must state the things that are true but not discoverable from
the code: which OpenCV is required and why, what the run's declared reductions are, what a
resume does, and which invocation lines have **never been rehearsed**.

That last item is D-21 and it is not optional. `e7_focal_standoff` has no `--smoke` branch and
reads a hardcoded path; `e4_repeat` refuses `--smoke` for both `--cell` and `--splice-repeat`.
Adding smoke branches is freeze-window code for diagnostic-only benefit, so they stay skipped —
**and naming that in the handoff note IS the mitigation.** An unstated untested path is the
F-001 shape.

Purpose: make the package self-describing.
Output: `experiments/HANDOFF.md`.
</objective>
