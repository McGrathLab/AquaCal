<objective>
`reconstruction_bootstrap.py:56` hardcodes `experiments/results/real_rig_metrics.json` instead of
honouring `--out` (D-23). It is correct in production — where `OUT_DIR == experiments/results` —
and wrong under `--smoke`, where `OUT_DIR` is `experiments/results_smoke` and the stage dies with
`FileNotFoundError` and **exit 1**.

That exit 1 is load-bearing now. D-20 (plan 27-03) makes every gate verdict green under smoke,
but the driver's final exit code also carries `STAGE FAILED: reconstruction_bootstrap (stage 10)
exited 1`. Without this fix, `--smoke` cannot exit 0 and plan 27-12's on-target verification
signal stays unusable.

Purpose: remove a hardcode of the same class the freeze exists to eliminate.
Output: `--out`-relative resolution with an honest degradation path.
</objective>
