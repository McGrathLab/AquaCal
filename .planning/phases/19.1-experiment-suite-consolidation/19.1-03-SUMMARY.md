# Phase 19.1 Plan 03: experiments/_io.py Shared I/O Layer Summary

**Built `experiments/_io.py`, the I/O-only shared layer every experiment script (E1, E2, E7) depends on: the five-flag argparse parent, the sort-before-write CSV writer with a resumability guard, the numeric `--check` comparator, and the direct-call `benchmark.json` wrapper reusing `aquacal.io.assemble_benchmark_record`.**

## Performance

- **Duration:** ~45 min
- **Tasks:** 2/2 completed
- **Files created:** 2 (`experiments/_io.py`, `tests/unit/test_experiments_io.py`)

## Accomplishments

- `experiments/_io.py` (I/O only, P3: no scientific computation) provides exactly six public callables plus the `ComparisonReport` result type.
- The shared five-flag CLI parent (`--seed`, `--out`, `--force`, `--smoke`, `--check`) is built with `add_help=False` so every `eN_*.py` script can extend it via `parents=[...]` without a duplicate `-h` conflict; `validate_args` enforces `--check`/`--force` mutual exclusivity via `parser.error()` (hard error, D-21).
- `write_experiment_csv` sorts by caller-declared `key_columns` (stable sort) before writing, reuses `aquacal.io.internals.warn_if_overwriting`, and honors the per-configuration resumability guard (skip unless `--force`, D-24).
- `compare_experiment_csv` realigns both frames on `key_columns` (not row index — Pitfall 5), delegates numeric comparison to `pandas.testing.assert_frame_equal(check_exact=False, rtol=...)`, additionally asserts non-float columns exactly, and reports the single worst-offending cell (key values, column, committed value, fresh value, relative difference) without ever writing to the committed baseline.
- `write_direct_call_benchmark` composes `capture_environment` + `assemble_benchmark_record` + `write_benchmark_json` unmodified, always passing `memory_readings=None` (D-11, no `capture_peak_memory` call anywhere in the module), and raises `ValueError` naming any `timings`/`diagnostics` key outside the settled two-key Phase-18 stage vocabulary (`stage3_interface_optimization`, `stage3_intrinsic_pass`).
- 17 new unit tests in `tests/unit/test_experiments_io.py`, grouped into `TestCli`, `TestCheckComparator`, `TestDeterminism`, `TestResume`, `TestRecord` (matching the validation contract's `-k` selectors), all fast (~1s total, no calibration, no slow marker).

## Decisions Made

- The worst-offending-cell report is assembled by scanning per-float-column relative differences (`abs(fresh - committed) / abs(committed or 1)`) after `assert_frame_equal` raises, rather than parsing pandas' own assertion message — gives full control over the exact fields the plan's acceptance criteria require (key values, column name, both raw values, relative difference).
- `write_direct_call_benchmark`'s stage-key guard checks both `timings` and `diagnostics` independently (not just their union), so a caller passing an unsettled key in either dict is caught with the specific key named.
