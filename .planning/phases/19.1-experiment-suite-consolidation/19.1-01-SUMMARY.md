# Phase 19.1 Plan 01: Promote Shared Experiment Verbs Summary

**Promoted `calibrate_synthetic`, `evaluate_reconstruction`, and `compute_per_camera_errors` from a test-only helper into `aquacal.datasets.pipelines`, widened the per-camera error return shape into a new `PerCameraErrors` TypedDict, and made `build_interface_spread_report` public.**

## Performance

- **Completed:** 2026-07-27T14:09:05Z
- **Tasks:** 3/3 completed

## Accomplishments
- `src/aquacal/datasets/pipelines.py` now holds the three promoted verbs with the three mandatory signature changes: `seed` is a real parameter (default 42), the `sys.path`/`tests.` import hack is gone (direct import from `aquacal.datasets.synthetic`), and `compute_per_camera_errors` is widened with six center columns, a repeated calibration-level RMS column, and an explicit `gauge_correct_z` keyword.
- `PerCameraErrors` TypedDict added to `src/aquacal/config/schema.py`, used as `compute_per_camera_errors`'s return annotation; its declared keys are asserted (by test and by manual verification) to match the function's runtime keys exactly.
- `aquacal.datasets.__all__` widened to 15 names (8 existing + 7 new): the three promoted verbs plus `generate_camera_array`, `generate_real_rig_array`, `generate_board_trajectory`, `generate_dense_xy_grid`. `generate_real_rig_trajectory` is deliberately absent (see Decisions).
- `tests/synthetic/experiment_helpers.py` collapsed from a 330-line implementation file to a 13-line re-export shim, mirroring `tests/synthetic/ground_truth.py`'s existing pattern.
- `_build_interface_spread_report` renamed (pure rename, no behavior change) to `build_interface_spread_report` and exported from `aquacal.calibration.__all__`, so E7 (plan 19.1-05) can reuse it instead of duplicating five lines of stats.
- Eight new unit tests added covering shim identity, widened keys, default-unchanged gauge behavior, the gauge correction's exact arithmetic (including the "not hardcoded to zero" guard on the reference camera), the reference camera's exact-zero XY error, seed determinism, and bit-exact repeatability.

## Decisions Made
- `PerCameraErrors` kept as a `dict`-shaped `TypedDict` rather than a dataclass or `DataFrame`, per the 2026-07-27 amendment to D-06.3 — costs nothing at runtime, changes no call site, and gives both a reader and a type checker the key list.
- `gauge_correct_z=True` applies a uniform subtraction across every camera including the reference camera (Pitfall 2 guard) rather than special-casing `cam0` to zero.
- `generate_real_rig_trajectory` excluded from the widened barrel (see Final `__all__` section above).
