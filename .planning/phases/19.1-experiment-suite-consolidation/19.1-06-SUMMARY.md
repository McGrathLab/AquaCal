## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2/3 - Missing critical functionality / blocking] Added `timings_out` out-parameter to `aquacal.datasets.pipelines.calibrate_synthetic`**
- **Found during:** Task 2, while implementing the direct-call benchmark record's `timings` block.
- **Issue:** `calibrate_synthetic` composes Stage 3 (`optimize_interface`) and Stage 3's second pass (`joint_refinement`) internally as a single call. The plan requires the benchmark record's `timings` dict to carry separate wall-clock seconds per settled stage key, but the experiment call site has no way to observe the boundary between the two internal calls without a hook analogous to the already-established `diagnostics_out` out-parameter.
- **Fix:** Added `timings_out: dict[str, float] | None = None` to `calibrate_synthetic`, populated via `time.perf_counter()` around each of the two internal stage calls, mirroring the exact pattern and docstring style of the existing `diagnostics_out` parameter. Default `None` leaves every existing caller (all of Phase 19.1's plans, tests) byte-identical.
- **Files modified:** `src/aquacal/datasets/pipelines.py`
- **Verification:** `python -m pytest tests/unit/test_datasets_pipelines.py -q` — 8/8 still pass unchanged (zero-numerical-change guard). `python -m pytest tests/ -m "not slow" -q` — 874 passed both before and after the fresh `--force` run.
- **Committed in:** `7dfcb2e` (Task 2 commit)

**2. [Rule 3 - Blocking] `exp2_spatial_errors.csv` gitignored, not committed**
- **Found during:** Task 3, staging the fresh output for commit.
- **Issue:** The fresh `exp2_spatial_errors.csv` is ~11MB (8 depths x 2 models x every adjacent-corner-pair over a dense `N_GRID=7` sweep), which exceeds this repo's `check-added-large-files --maxkb=1000` pre-commit gate. Committing it as written would fail the hook.
- **Fix:** Added a targeted `.gitignore` entry for `experiments/results/exp2_spatial_errors.csv`, documented inline with the reasoning (no committed baseline per D-20, not compared by `--check`, fully reproducible via `--force`). The file remains on disk, satisfying "E1 still emits it."
