- To satisfy the plan's diff-based acceptance criterion for `_render.py` (`diff <(git show 93cb1f3:benchmarks/aggregate.py | grep -v '^#' | grep -v benchmarks) <(grep -v '^#' experiments/_render.py | grep -v experiments)` must show no differences), I updated all three docstring occurrences of the `benchmarks/` path in `_render.py` (module docstring first paragraph, the "Run manually" example command, and `_build_arg_parser`'s own docstring) — not just one — because any one being left stale broke the symmetric grep-filter comparison. Verified: the diff now shows zero differences.
- For `experiments/e4_benchmark_grid.py`, the plan explicitly scoped the permitted edits to exactly two: the module docstring's path reference and the `__main__` block's import. `_build_arg_parser`'s docstring there still says `python benchmarks/sweep_runner.py` — left as-is because the plan named only two edits for this file and no acceptance criterion checks that specific string; it does not match any of the "no live reference" grep patterns (`from benchmarks`, `benchmarks\.aggregate`, `benchmarks\.sweep_runner`), so it does not violate EXP-03.
