- cam2: translated 0.1m in Y (R=I, t=[0, 0.1, 0])

- Add small Gaussian noise (sigma=0.5 px) to observations
- Include all 3 cameras per correspondence (some can have only 2)
- All weights = 1.0

- cam2.t += [0, 0.005, 0]
- water_z += 0.01 (perturbed by 1cm)
This simulates a "close but not perfect" calibration that refinement should improve.

<task type="auto">
  <name>Task 2: Write comprehensive test cases for refine_calibration</name>
  <files>tests/unit/test_point_refinement.py</files>
  <action>
Add test classes and methods to `tests/unit/test_point_refinement.py`:

**class TestInputValidation:**
- `test_empty_correspondences_raises` — empty list raises ValueError
- `test_negative_weight_raises` — weight=-1 raises ValueError
- `test_unknown_camera_raises` — observation for "camX" raises ValueError
- `test_too_few_observations_raises` — correspondence with only 1 camera raises ValueError
- `test_too_few_correspondences_raises` — fewer than minimum threshold raises InsufficientDataError
- `test_zero_weight_silently_dropped` — 15 correspondences with weight=0 + 15 with weight=1 works (the zeros are just dropped)
- `test_all_zero_weight_raises` — all zero weights means no valid correspondences, raises InsufficientDataError
- `test_bad_point_shape_raises` — point_3d with shape (2,) raises ValueError
- `test_bad_pixel_shape_raises` — observation pixel with shape (3,) raises ValueError

**class TestRefinementOptimization:**
- `test_refinement_reduces_reprojection_error` — Using `perturbed_result` and `synthetic_correspondences`, run refine_calibration and verify the RMS reprojection error decreases compared to the perturbed result's reprojection error. Compute reprojection error by projecting all correspondence points through the refined cameras and comparing to observations.
- `test_intrinsics_unchanged` — After refinement, every camera's K matrix and dist_coeffs must be identical to the input
- `test_extrinsics_change` — After refinement from perturbed_result, at least one non-reference camera's extrinsics must differ from input (optimization actually moved something)
- `test_reference_camera_fixed` — Reference camera (cam0, first sorted) R and t unchanged after refinement
- `test_water_z_positive` — After refinement, water_z > 0 for all cameras
- `test_returns_calibration_result` — Return type is CalibrationResult, has all expected fields
- `test_verbose_flag_accepted` — `refine_calibration(result, corr, verbose=True)` runs without error (just testing it doesn't crash)

**class TestEdgeCases:**
- `test_already_optimal_calibration` — Using ground truth calibration + noiseless correspondences, refinement should converge quickly and not blow up. RMS should be very small (<1 px).
- `test_weighted_correspondences` — Some correspondences with weight=2.0 and some with weight=0.5; refinement completes without error

Mark the optimization tests with `@pytest.mark.slow` since they run actual bundle adjustment.

Each test should be self-contained and use the fixtures. Keep assertions specific and meaningful.
