<objective>
Land the returned run in git — exactly 227 files, byte-for-byte, on `results/rerun-freeze-02` —
and prove afterwards that the bytes and the single-sha property both survived.

Purpose: RUN-04. This is the act that turns the run into the repository's committed evidence base.
Its whole risk is a one-character rewrite: `end-of-file-fixer` and `trailing-whitespace` would
touch 147 of the 227 files, and a whitespace-only rewrite does not change a measurement but it does
change bytes the gate reads and it destroys the "byte-for-byte what the run produced" claim. That
hazard is currently latent — no hook is installed in either clone, `pre-commit` is not on `PATH`,
and CI's `pre-commit run --all-files` fires only for `main` — and this plan's job is to keep it
latent while the commit lands.

D-29-19 is discharged here too, and by construction rather than by prose: the three generated LaTeX
fragments §3 includes are inside the 147, so committing the admitted set commits the traceability
mechanism alongside the artifacts that produced it, with Gate 3 supplying the single-sha proof.
This phase deliberately does **not** build a mapping document against the manuscript — that is
POST-01, in Phase 30.

Output: one artifacts commit and a post-commit gate re-run.
</objective>
