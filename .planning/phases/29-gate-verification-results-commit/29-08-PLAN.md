**Trigger:** the assumption-delta scan fired on this phase. The genuine delta is a
**pluralization**: `src/aquacal/datasets/data/manifest.json` pins `zenodo_record_id: 21889922` — a
**single** record id, in a schema that describes **one** file with **one** checksum — and RUN-05
splits the archive into **two** records with different lifecycles.

**The noun that is now primary:** a *dataset* is no longer one Zenodo record. It is an **input
record plus a results record**, and the results record is independently re-versioned. The
`zenodo_record_id` / `zenodo_filename` / `checksum` triple is a description of one variant, not of
the identity.

**Decision: `no-change` in Phase 29 — the promote-vs-add-alongside ruling is transferred to
Phase 30 / POST-01.** Rationale: nothing in Phase 29 needs the pin to move, because both new
records are unpublished drafts with no DOIs until the author acts, and record `21889922` remains
published, valid and citable throughout. Repointing would touch ten sites, **four of them inside
the frozen `experiments/` tree** (`reconstruction_bootstrap.py`, `e2_real_rig.py`,
`suite_expectations.json`, `FROZEN-ROWS.md`) — changing source files at the tag the run was made
from, which is a materially different act from committing that run's output.

**Explicit warning attached to the deferral:** when Phase 30 takes it up, the correct move is
almost certainly to **promote** — represent the dataset as a set of records and demote
`zenodo_record_id` to one variant's detail — rather than to **add a second id alongside a still-required
first**. Adding alongside would silently keep the singular assumption: a future third record (a
second results version, say) could be stored but never resolved as the default. The two `tests/`
assertions that hard-code `21889922` (`test_datasets.py:577`,
`test_stale_provenance_strings.py:120, 176`) are the cheap half and are the first things to change.

**Suggested invariant test for Phase 30 (not built here):** every dataset the manifest declares
round-trips through `download_and_extract` into the cache layout `loader.py` expects, for **every**
declared record — a test that goes red the instant a second record is bolted on without the loader
learning to compose them.
</assumption_delta_decision>
