**Always `python -u`.** Python block-buffers stdout when it is a pipe rather than a terminal, so
without it a background run shows an empty log whether it is progressing normally or hung on the
first configuration — the two are indistinguishable, and a real stall stays invisible until the
timeout.

**Judge by `status` counts, never the exit code.** Plan 05 makes a failing run exit non-zero, but
the habit stands: read the counts.

**Commit nothing between the pre-run record and the post-run comparison.** A per-cell
`git rev-parse` during a production run splits an artifact's recorded SHA across two commits. Take
HEAD once, before launching, and leave the tree frozen until step 5 is complete and compared.

**Anti-pattern 3 is blocking.** The seed-42 comparison is a byte-identity gate against a committed
artifact. If it fails outside the declared columns, **the fix moves — never the tolerance, never
the committed artifact, and never the declaration written in step 1.**

**Anti-pattern 4 is blocking.** `--smoke` proves the path runs; it may NOT stand in as proof the
fix is correct. Every geometry variant converges at 6 frames with the bug present; the failure
needs ~50.
