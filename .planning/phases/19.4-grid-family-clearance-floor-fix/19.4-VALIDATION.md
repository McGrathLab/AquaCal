## Sampling Rate

- **After every task commit:** `python -m pytest tests/ -m "not slow"`
- **After every plan wave:** `python -m pytest tests/` (full, unfiltered — matches
  `prelaunch_gate.sh`'s SUITE_GREEN bar)
- **Before the production queue launches:** full suite green **and** the complete cheap-gate
  ladder green **and** D-19.4-17's coverage matrix reviewed
- **Max feedback latency:** ~240 s for the quick run

### Cheap-gate ladder (D-19.4-16) — runs before any production stage

| Gate | Cost | Catches |
|------|------|---------|
| Legality sweep (13,500 scenarios) | ~8 s | scenario-construction illegality |
| Bit-inertness (E1/E3/E5/E7) | ~10 s | unintended movement in the inert set |
| E6 `--smoke` | 5–10 min | wiring / CLI / checkpoint-identity breakage |
| Full unit suite | ~25 min | everything unit-testable |

**What the ladder provably cannot catch:** convergence behaviour at production frame counts,
and memory behaviour at production scale (E4's 10.26 GiB 16×200 peak is invisible to any smoke
run). This is precisely why D-19.4-16 reorders the queue risk-first rather than trusting the
gates alone. Anti-pattern 4 is binding: `--smoke` is not proof.
