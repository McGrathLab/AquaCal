<objective>
Execute the ~9 h 30 min production queue exactly once, in the order plan 08 encoded, and confirm
every stage completed under one git sha (SC-5, SC-7).

Purpose: the phase's deliverable is not "the interface is fixed" — it is a complete, coherent,
current result set that a reviewer could re-run and reproduce and that the author can lift numbers
from directly. Every experiment is re-run, not just the two that change: "expected inert" is not
"proven inert", and E1/E3/E5/E7 cost only 28 min of the total.

Output: a full `experiments/results/` regenerated under a single git sha, plus the state file and
log as the run's record.

**THIS PLAN CHANGES NO CODE.** It is deliberately separated from every code-changing plan. Its
`files_modified` are outputs and run records only.

**Execution discipline — this is the plan the project has repeatedly lost hours to:**
- This plan is executed INLINE by the orchestrator, not delegated to a spawned executor. 19.3's
  plan 09 did the same (its Deviation 3) for the same reason: an executor that launches a long
  run as a background job and returns "waiting for the notification" has stalled and will not come
  back. That has cost multiple hours across phases 19.2 and 19.3.
- The queue is launched with `nohup ... & disown` and then POLLED SYNCHRONOUSLY. It is never
  launched with `run_in_background` — that harness kills background commands at 35-50 min and this
  project has already lost three sweeps to it.
- Never trust a return text as evidence. Verify against the filesystem and git:
  `experiments/rerun_19_4_state.tsv`, `experiments/rerun_19_4.log`, and
  `git log --oneline`.

**The abort protocol is pre-committed (D-19.4-16). Do not re-decide it mid-run:**
1. A src defect discovered at any stage → abort the queue, fix, restart from stage 1.
2. NEVER edit `src/` or `experiments/` while the queue is in flight. 19.3's run holds one git sha
   across every artifact; a midstream edit destroys that silently and yields a result set
   assembled from two different trees. That is unreportable, and the damage is invisible until
   someone diffs provenance.
3. A cross-stage sha mismatch is a HARD failure, not a warning.
4. Commit nothing while the queue runs — a per-cell `git rev-parse` would split an artifact's
   recorded sha across the boundary.
The `bash experiments/rerun_19_4.sh N` resume argument exists for INFRASTRUCTURE failures (box
reboot) only. It is never the response to a src defect.
</objective>
