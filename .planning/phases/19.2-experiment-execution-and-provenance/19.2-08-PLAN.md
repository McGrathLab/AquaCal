<objective>
Write `experiments/e5_index_sensitivity.py`: sweep the assumed refractive index in a fine band
around 1.333 on the real rig's geometry, and report depth/scale bias and held-out reprojection
RMSE against Δn.

Purpose: EXP-09 answers R2 by **refuting its premise**. The reviewer's concern is that miniscule
changes in `n` could ruin the calibration; the expected result is that index error maps almost
entirely into a small apparent-depth scale bias rather than into reprojection residuals, because
`n` and depth are coupled (`Δdepth/depth ≈ Δn/n`). The argument needs both quantities — the point
is that the bias moves while the residual does not.
Output: one script, one committed CSV, fast unit tests, and a completed production sweep.

**E5 needs NO library change.** `calibrate_synthetic`'s existing `n_water` argument is already the
*assumed* index threaded into Stages 2 and 3, and after plan 19.2-01 the scenario's own `n_water`
is the *true* index used for generation. E5's procedure is therefore
`calibrate_synthetic(scenario, n_water=n_assumed)` as shipped — the same mechanism E1's
non-refractive arm already uses. Do not add a parameter for E5's sake.
</objective>

      # no parameters; 12 cameras cam0..cam11 at hardcoded XY from an actual rig calibration,
      # common averaged intrinsics (fx 1587.79, fy 1588.34, image_size (1600,1200)),
      # common water_z = 1.031, all at world Z=0, all identity rotation.
  generate_real_rig_trajectory(n_frames=100, depth_range=(1.1,2.0), seed=42) -> list[BoardPose]
      # footprint constants X_CENTER=-0.34, Y_CENTER=0.55, XY_EXTENT=0.7,
      # ROTATION_RANGE_DEG=20.0 are hardcoded inside the body, NOT parameters.
  Board config to use (the same literal create_scenario builds inline; import it from
  experiments.e4_benchmark_grid.GRID_BOARD_CONFIG rather than declaring a third copy):
      BoardConfig(squares_x=12, squares_y=9, square_size=0.060, marker_size=0.045,
                  dictionary="DICT_5X5_100")

  SyntheticScenario fields: name, board_config, intrinsics, extrinsics, water_zs, board_poses,
      noise_std, description, images=None, n_air=1.0, n_water=1.333, seed=42

Sweep mechanics:
  calibrate_synthetic(scenario, n_water=n_assumed, refine_intrinsics=..., seed=...)
      # scenario.n_water is n_true (generation); the n_water argument is n_assumed (calibration)
  generate_synthetic_detections(intrinsics, extrinsics, water_zs, board, board_poses,
      noise_std, n_air, n_water, seed)     # used directly for the held-out set at n_true
  evaluate_calibration(calibration, detections, board, min_corners=8, cameras=None,
      board_poses=None, include_reconstruction=True) -> HeldOutEvaluation
      # There is NO n_water override. n_air/n_water/interface_normal always come from
      # `calibration.interface` — i.e. whatever the calibration assumed. The wrong assumption is
      # encoded entirely in the held-out detections being generated at n_true.
      # THIS IS E5's WHOLE MECHANISM. A runnable docstring example lives at evaluation.py:135-147.
      # Use evaluate_calibration, NOT evaluate_reconstruction (which estimates no board poses).

  HeldOutEvaluation.reconstruction is a DistanceErrors with fields:
      mean, std, max_error, num_comparisons, per_corner_pair, signed_mean, rmse,
      percent_error, num_frames, spatial
      # signed_mean is in METRES, + = overestimate. This is the depth/scale-bias substrate.
  HeldOutEvaluation.reprojection is a ReprojectionErrors.

E1's existing scale-factor expression, currently INLINE at

  The 60 mm denominator is the board's own `square_size` in mm.
