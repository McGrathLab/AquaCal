## Decisions Made

- Kept `normal_fixed`'s default at `True` (matching `optimize_interface`/`joint_refinement`'s own library defaults) rather than flipping any default, so every already-committed Phase-19.1 record (E1, E7) stays bit-identical and is never re-run — appending it last in the signature was the mechanism that made this a zero-signature-break change.
- D-23 closed with no new parameter: `scenario.n_air`/`scenario.n_water` is now honored as the *generated* (true) index; `calibrate_synthetic`'s existing `n_water` argument remains the *assumed* index used by `estimate_extrinsics`/`optimize_interface`/`joint_refinement`. The two are now independently controllable, as E5 and E6 both need.
- `_baseline` memory capture placed immediately before `build_pose_graph` rather than before board-geometry/detection generation, per the plan's explicit read_first pointer to the pipeline's own `_baseline` semantics (pre-Stage-2, not pre-detection).
