<objective>
Write `experiments/e3_derived_quantities.py`: the three-tier derived-quantities script that turns
every supplement claim about *how the library behaves* into a committed, regenerable artifact.

Purpose: EXP-07. Tier 1 renders the declared constants table CI already owns; tier 2 measures the
Newton iteration distribution the supplement asserts as "two to four steps" but never measured;
tier 3 emits `P` / group counts for **all six** `tab:cpr` rows.

**Tier 3's scope was widened during the cross-AI review (H1) and this is settled, not open.** The
original design split `tab:cpr` across `cpr_grouping.csv` and E4's `benchmark_grid.csv` (D-16).
That split does not hold: every `tab:cpr` row is a tilt-enabled (`normal_fixed=False`)
configuration, and the four rows assigned to E4 would have been produced by a run whose parameter
vector is two tilt DOF smaller — a wrong number that looks right. Tier 3 builds sparsity patterns
without calibrating, so covering all six costs seconds. E3 therefore owns every `tab:cpr` row and
the cross-file split is retired. E4 still reports CPR columns, but they describe **E4's own
configuration** and are labelled as such; they do not feed `tab:cpr`.
Output: one script, four data artifacts, two LaTeX fragments, one provenance sidecar, and unit
tests over its novel helpers.
</objective>
