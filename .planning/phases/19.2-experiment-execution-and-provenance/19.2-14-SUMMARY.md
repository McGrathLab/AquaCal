# Phase 19.2 Plan 14: Seed provenance in pipeline solver_config Summary

Added `config.seed` as a fifth, purely additive key in `run_calibration_from_config`'s
`solver_config` dict, and proved the addition is numerically inert with an exact-equality
test anchored to pre-change values captured from commit `e1d6548dbe807eb0abc0d0e8f8c1f9c0065d7477`.

## Deviations from Plan

None -- plan executed exactly as written. One implementation choice made within the
plan's latitude: the anchor scenario is `"ideal"` rather than `"minimal"`, because
`"minimal"`'s 2-camera holdout split produced zero valid 3D-comparison pairs
(`validation_3d_error_mean = NaN`), which cannot serve as a frozen exact-equality
constant. `"ideal"` (4 cameras, 20 frames, zero noise) gives clean near-machine-precision
numbers and is the same scenario `TestBenchmarkJsonIntegration`'s existing tests already use.
