on E5's code existing.

`CLAUDE.md`; without `-u` the log stays empty for the entire run and a stall is indistinguishable
from progress.

Entry point: `python -u -m experiments.e5_index_sensitivity --force`
  Runs every entry of `N_ASSUMED_BAND` (a literal list spanning roughly +/-0.01 around 1.333 at
  ~0.002 steps, 11 points, with 1.333 itself present as the zero-delta control) on the real rig's
  geometry, and writes `index_sensitivity.csv` with columns `E5_COLUMNS`, keyed on `["n_assumed"]`.

`E5_COLUMNS` (17, from plan 19.2-08):
  seed, n_true, n_assumed, delta_n, delta_n_over_n, reprojection_rms_px,
  reconstruction_mae_mm, reconstruction_rmse_mm, signed_mean_mm, scale_bias_frac,
  scale_bias_pct, scale_bias_pct_control, bias_over_control,
  holdout_floor_pct, scale_bias_over_floor, num_comparisons, num_frames

  scale_bias_pct_control is the Δn = 0 row's own bias, repeated on every row; bias_over_control is
  `abs(scale_bias_pct - scale_bias_pct_control)`. These are E5's INTERNAL control (review M6).
  holdout_floor_pct / scale_bias_over_floor express the same bias against E2's real-rig held-out
  RMSE — a cross-dataset, cross-quantity ratio. Both are reported; neither alone carries the
  argument.

Resumability: `write_experiment_csv` skips a write when the file exists and `force` is False. That
is FILE-level, not row-level — an interrupted E5 run restarts. The band is ~11 points, so this is
acceptable; E6 (the far larger sweep) got per-configuration checkpoints instead.

The tilt configuration: E5 runs at `E5_NORMAL_FIXED = False`, matching
`CalibrationConfig.interface_normal_fixed` and therefore E2, whose held-out floor is E5's yardstick.
