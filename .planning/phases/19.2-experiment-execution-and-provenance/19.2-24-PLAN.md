<objective>
Widen the mechanical EXP-11 gate so the failure it missed cannot recur, and re-assert on the final
merged tree that the two experiments this phase never re-runs still reproduce.

Purpose: EXP-11. The gap that failed verification was not subtle in the artifacts — neither E5 nor
E6 imported any provenance helper — but it *was* invisible to the gate, because the one test covering
those two files checks a `seed` column and nothing else, and both its docstring and the README narrate
that narrow check in language that reads like full coverage. **This is exactly the failure mode the
phase was meant to eliminate: a provenance claim that is true of most artifacts, asserted as if true
of all.**

Waves 3–5 regenerated E4's, E6's, E5's and E3's artifacts with real provenance. This plan makes the
gate enforce what those artifacts now carry, so the next artifact committed without provenance fails
a test rather than a verification pass six weeks later.

Output: a provenance suite that enforces four fields per artifact and cannot be weakened by an absent
file, plus recorded `--check` reproductions for E1 and E7 on the final tree.

**Do not widen `SEEDLESS_LEGACY_RECORDS`.** It was audited and holds up: exactly six members, all
Phase-19.1 records that genuinely predate `solver_config["seed"]`, each asserted to exist *and* to
still lack a seed so the exemption self-destructs the moment one is regenerated, cardinality pinned,
E2 explicitly excluded, and all six still held to the environment check. The carve-out is one field
wide, not blanket. Adding a member to make a new test pass would convert a defended exemption into
the blanket one it was designed not to be.
</objective>
