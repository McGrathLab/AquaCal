## `expected_P` Term List (verified against `pack_params`'s body)

```
tilt        = 0 if normal_fixed else 2                 # reference camera rx, ry
extrinsics  = 6 * (n_cams - 1)                          # rvec(3)+tvec(3) per non-reference camera
water_z     = 1 if shared_interface else n_cams         # single global vs. one per camera
poses       = 6 * n_frames                              # rvec(3)+tvec(3) per frame
intrinsics  = 4 * n_cams if refine_intrinsics else 0    # fx,fy,cx,cy per camera
P = tilt + extrinsics + water_z + poses + intrinsics
```

Validated across 6 configurations: `(3,4,T,F,T)`, `(3,4,F,T,T)`, `(3,4,T,F,F)`, `(5,6,F,F,T)`,
`(5,6,T,T,T)`, `(5,6,F,T,F)` (tuples: `n_cams, n_frames, normal_fixed, refine_intrinsics,
shared_interface`) -- against both `len(pack_params(...))` and
`build_jacobian_sparsity(...).shape[1]`.

## D-21 Group-Count Invariance (confirmed by measurement)

For a fixed 4-camera, 5-frame, `normal_fixed=True`, `refine_intrinsics=False` configuration:

- `P` grows from shared to per-camera mode: `S_pc.shape[1] - S_shared.shape[1] == n_cams - 1` (3).
- The structural FD group count is unchanged: `groups_pc.max()+1 == groups_shared.max()+1` (both
  13) -- per-camera `water_z` columns never share a residual row with each other, so they collapse
  into the same group slot the single shared `water_z` column occupied.

## Decisions Made

- Kept `DECLARED_CONSTANTS`'s `source` field as dotted module paths (e.g.
  `aquacal.calibration._optim_common.build_bounds`), sometimes semicolon-joined when a claim spans
  two call sites (`huber_f_scale_px`, `solver_tolerances`) -- never a line number, satisfying the
  structural `:\d+` gate.
- For `refined_intrinsics_bounds_frac`, used round nominal values (`fx_nominal = 1000.0`) so the
  bound-fraction division (`lower[i] / fx_nominal`) is bit-exact against the declared `(0.5, 2.0)`
  rather than requiring a `math.isclose` tolerance.
- `solver_tolerances`'s live scenario mirrors `tests/unit/test_benchmark.py`'s
  `real_solver_diagnostics` fixture (3 cameras, 3 frames) to stay well under a second; measured at
  ~1.6s for the full 34-test combined run of both new files, so no test needed a `slow` marker.
