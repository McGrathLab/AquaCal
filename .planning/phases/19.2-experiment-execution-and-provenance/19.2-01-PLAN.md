<objective>
Make `calibrate_synthetic` able to (a) report per-stage peak memory through a new optional
`memory_out` out-parameter (D-06) and (b) honor `scenario.n_air` / `scenario.n_water` when
generating its detections (D-23) — both as zero-numerical-change edits guarded by exact-equality
tests.

Purpose: E4's nine synthetic grid cells cannot record stage-attributed memory without (a), and
E6's refractive-index axis measures nothing without (b) — every scenario in the sweep would be
silently generated at 1.333 and produce a null result that looks like data.
Output: two new behaviors on one shipped public function, plus four new tests proving neither
changes an existing caller's numbers.
</objective>
