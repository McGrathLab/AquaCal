<objective>
Add `seed` to the `solver_config` block that `run_calibration_from_config` passes into
`assemble_benchmark_record`, so a pipeline-written `benchmark.json` carries the seed that drove
the run — and prove the addition is numerically inert.

Purpose: **D-26 requires this and plan 19.2-06 blocks on it.** Verified at
`src/aquacal/calibration/pipeline.py:1736-1741`, `solver_config` is a four-key literal
(`robust_loss`, `loss_scale`, `refine_intrinsics`, `interface_normal_fixed`). `CalibrationConfig.seed`
exists (`src/aquacal/config/schema.py:365`, default `42`) and is threaded into the holdout split and
into `CalibrationMetadata` — but it never reaches `solver_config`. Review finding H5's seed threading
went into `experiments/_io.py::write_direct_call_benchmark`, which serves the **direct-call** path
(E1, E4, E7). E2 goes through `run_calibration_from_config` and was missed. Without this plan,
plan 19.2-06's refreshed `experiments/results/benchmark.json` would fail plan 19.2-12's own
`test_every_benchmark_record_carries_a_seed`, and EXP-11's headline requirement — every committed
result carries its seed — would be false of the phase's single most-cited record.

Output: a one-key additive change to a provenance dict, plus the exact-equality guard that makes it
a *proven* zero-numerical-change edit rather than an obviously-harmless-looking one.

**Why this is its own plan rather than tasks appended to 19.2-02.** Plan 19.2-02 already carries two
tasks at its context budget, is cross-AI reviewed, and owns a different file set and a different
requirement (EXP-08 diagnostics plumbing). This change touches a file no other plan in the phase
touches (`calibration/pipeline.py`), serves EXP-11, and needs its own end-to-end guard through
`tests/synthetic/test_full_pipeline.py`'s pipeline harness. Keeping it separate preserves
19.2-02's single concern and gives plan 19.2-06 a named, independently verifiable dependency.

**Why it is wave 1.** D-26: all `src` changes land, and are proven inert, before any experiment that
yields a publishable result. `files_modified` collides with no other wave-1 plan — 19.2-01 owns
`datasets/pipelines.py`, 19.2-02 owns `_observability.py` / `interface_estimation.py` /
`refinement.py` / `experiments/_io.py`, 19.2-03 owns `core/refractive_geometry.py`, 19.2-04 owns
two E3 test files.
</objective>
