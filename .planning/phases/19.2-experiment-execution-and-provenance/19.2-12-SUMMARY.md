## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed a second, distinct defect in `experiments/_io.py`'s `compare_experiment_csv`**
- **Found during:** Task 1 setup, while re-verifying the upstream findings the orchestrator flagged (E6's `--check` exit-1 "same class of defect" dismissal was suspect per the prompt's explicit instruction to investigate rather than dismiss by analogy).
- **Issue:** 19.2-09's fix handles a column that is ALL empty strings on the fresh side (round-trips to an all-NaN float64 column on the committed side). E6's `status_reason` column is MIXED -- 13 `""` rows plus one real string (`"KeyError: 'cam11'"`). A column with a real string present stays object/`str`-dtype on CSV read-back (pandas does not infer it as float64), so 19.2-09's `is_float_dtype(committed)` branch never triggers. But the `""` cells still round-trip through CSV as an empty field indistinguishable from a missing value, so `pd.read_csv` reads them back as a real `NaN` sitting inside that otherwise string-dtype column. The exact-compare loop's `!=` then reported all 13 `""` rows as mismatched against `NaN`, which is exactly the "13 of 14 cells mismatched, all on status_reason" 19.2-11 observed and (incorrectly) dismissed as benign.
- **Fix:** Normalize `NaN` -> `""` on both `fresh_sorted` and `committed_sorted` for every column already classified as non-float, immediately before the exact-comparison loop. Verified this does not mask a genuine mismatch (new regression test asserts a real differing string still fails).
- **Files modified:** `experiments/_io.py`; `tests/unit/test_experiments_io.py` (two new regression tests: one proving the mixed-column false-positive is fixed, one proving a genuine mismatch in that same column shape still fails).
- **Verification:** `pytest tests/unit/test_experiments_io.py -q` -- 28 passed. `python -m experiments.e6_generalization_sweep --check` now exits 0 (was 1). `python -m experiments.e4_benchmark_grid --check` still exits 1, confined to `exit_code` only (unchanged -- the fix did not paper over E4's genuinely-structural caveat).
