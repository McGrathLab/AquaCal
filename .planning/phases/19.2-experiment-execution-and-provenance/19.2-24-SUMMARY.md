## Decisions Made

- Kept `benchmark_grid.csv` on the simpler seed-column-only check rather than forcing it through the
  same sidecar-lookup path as `index_sensitivity.csv`/`generalization_sweep.csv`: it has no single
  backing record (nine `e4_cells/*/benchmark.json` + `benchmark.json`), and those records' full
  four-field provenance is already independently asserted by `TestE4CellProvenance` and
  `TestOneMachineConsistency`. Forcing a synthetic single-record mapping for it would have added
  indirection without adding coverage.
- For the e3 anchor fix, chose a frozen literal over an archived pre-D-32 CSV copy under
  `experiments/archive/`. Rejected the archive approach because an external file is itself something
  a later cleanup pass could move, rename, or delete without any test failing to notice — the same
  class of problem this fix exists to solve. A literal embedded in the test file cannot drift out from
  under it.
