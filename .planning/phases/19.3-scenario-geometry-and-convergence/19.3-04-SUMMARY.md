# Phase 19.3 Plan 04: Real-Rig Standoff Finished Into the Library Summary

**Moves `generate_camera_array`'s default `height_above_water` and both `create_scenario` shallow presets off the old 0.15 m literal onto the real-rig standoff (module-level `WATER_Z` = 1.031 m), regenerates the two frozen anchors this legitimately broke, and repairs the tutorial notebook's now-stale "small preset" description -- so the library can no longer construct a mis-framed rig by accident (D-19.3-09).**

## Accomplishments

- Hoisted `WATER_Z` out of `generate_real_rig_array` (where it was a local variable) into a module-level frozen constant, and changed `generate_camera_array`'s `height_above_water` default from `0.15` to `WATER_Z` (referenced by name, not restated).

## Decisions Made

- **`WATER_Z` hoisted to module level, not restated.** It previously existed only as a local variable inside `generate_real_rig_array`. Since `generate_camera_array`'s new default must reference it *by name* (per the plan's own acceptance criteria: `inspect.signature(...).default equals WATER_Z`), it had to become a module-level name defined before `generate_camera_array` in the file. `generate_real_rig_array` now references the same module-level constant instead of redefining it, preserving the exact numeric value and its full frozen-design-constant provenance comment (moved, not duplicated).
- **Two `test_synthetic_sweep_axes.py` tests fixed as an in-task auto-fix, not a separate deviation-tracked task.** `test_tank_scale_axis_is_independent` and `test_working_distance_axis_is_independent` both called `generate_camera_array` without `height_above_water=`, so they silently inherited the new default, and their hardcoded `depth_range` literals (`(0.3, 0.6)`, `(0.30, 0.45)`, `(0.8, 1.0)`) became illegal (below the new derived floor). Fixed by deriving `depth_range` from `board_clearance_floor` at each test's own array, preserving each test's actual assertion (axis independence), consistent with how every other test in the file already handles derived floors.
- **Both frozen anchors' guarding test docstrings were extended, not replaced**, appending a "second regeneration" section that names the specific cause (this plan, D-19.3-09) alongside the first regeneration's existing record (D-27), so the full provenance chain stays legible in one place.
