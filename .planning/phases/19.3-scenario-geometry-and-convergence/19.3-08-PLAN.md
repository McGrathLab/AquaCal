**Why E3 is in this queue (amendment, user-approved 2026-08-02):** `19.3-SEED.md`'s blast-radius
table listed five experiments and omitted E3. That omission was wrong — E3 calls
`generate_real_rig_trajectory` (`e3_derived_quantities.py:331`), so the re-centred, deeper geometry
moves its sampled incidence angles. Plan 19.3-05 measured the consequence: `newton_iterations.csv`
mismatches the committed baseline by **134 cells**. That file is the evidence behind **MF-01** (the
supplement's "two to four steps" Newton claim), so a stale committed artifact disagreeing with the
shipped code is exactly the defect class this phase exists to eliminate. GEOM-05 now names six
experiments.

**Locked operational constraints:**
- Launch detached with `nohup ... & disown`, NEVER `run_in_background`. The harness kills
  background commands at ~35-50 min; this has already cost this project three sweeps.
- One production run at a time on the box (review H4). Serial, not parallel. E3 costs minutes and
  runs no calibration, so it does not need the box to itself — but it still runs INSIDE the frozen
  queue window, after the pre-launch gate and before any commit, so its artifacts carry the same
  `git_sha` as everything else.
- Commit NOTHING while a run is in flight — per-cell `git_sha` capture would split an artifact's
  recorded provenance across two commits.
- All runs at production scale. A `--smoke` pass may not stand in as proof (anti-pattern #4).

    1. `python -u -m experiments.e3_derived_quantities --check` FIRST, with its full tier-by-tier

    2. `python -u -m experiments.e3_derived_quantities --force` SECOND, regenerating the committed

    geometry-dependent and are EXPECTED unmoved. **Confirm that by running, do not assume it.** If
    tier 1 or tier 3 moved, that is a FINDING that must be visible in the log and carried to plan
    10 — running `--force` first would regenerate it away and destroy the evidence. Put that reason
    in a comment beside the two invocations.

    Every python invocation uses `python -u`. Without it, stdout block-buffers into the log and a
    stalled run is indistinguishable from a healthy one for the entire night.

    The script itself is invoked detached by plan 09 as `nohup bash experiments/rerun_19_3.sh > <log> 2>&1 & disown`
    -- write it so that works: no interactive prompts, no reliance on a tty, absolute or
