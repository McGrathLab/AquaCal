## Decisions Made
- **Copy-vs-pointer decided by inspection, not category.** Rather than assuming every JSON needs a pointer, each candidate file was `grep -c git_sha`'d first: `interface_ablation_conditioning.json` has zero occurrences (pre-dates the `assemble_benchmark_record` schema) and was copied at 67 KB; every `assemble_benchmark_record`-shaped file (two occurrences of `git_sha` each: `environment.git_sha` plus `git_sha_source`) was pointed at instead.
- **Producing commits are read from each artifact's own sidecar, verified consistent across siblings.** For E4 and E6, all nine cell records / twelve config checkpoints were confirmed to share one identical `environment.git_sha` before it was used as "the" producing commit for that experiment's README — a spot-check would have missed a divergent cell silently.
- **No forced edit to `experiments/README.md`'s existing sections** — the plan explicitly allowed saying so in the SUMMARY if no natural place existed; here one did exist (section 7, "Reproducing a number"), so a new section 8 was added immediately after it rather than interleaving into an existing numbered list.
- **Directory dates use `2026-08-02` per the plan's explicit naming (`e{N}-2026-08-02-pre-depth-fix`) and the must_haves artifact paths**, even though the archiving work itself was done on 2026-08-01/02 boundary — this is the name the plan and CONTEXT.md's must_haves both specify, not a typo to correct.
