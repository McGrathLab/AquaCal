# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each constraint below was discovered through failure
> during the wave 1–2 execution of this phase.

- [ ] CONSTRAINT: **Executor worktrees can fork from a stale base.** Plan 18-01's worktree
      came up on `b4da55b` (v1.8.0), several commits behind the intended base. It
      self-corrected only because the dispatch prompt carried an explicit `EXPECTED_BASE`
      assertion with a `git reset --hard` recovery. Without that assertion an executor
      silently reverts its predecessors' work and the merge looks clean. — **Mitigation:
      every executor prompt MUST embed the current HEAD sha as `EXPECTED_BASE` and assert
      `git merge-base HEAD <sha> == <sha>` before any edit. Do not remove this block.**

**Do not proceed until the box above is checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Stale worktree base | Executor worktree HEAD started several commits behind the orchestrator's HEAD (observed on 18-01). Would have silently reverted predecessor work had 18-04 inherited it. | blocking | `EXPECTED_BASE` sha + `merge-base` assertion + `git reset --hard` recovery embedded in every executor dispatch prompt, verified before the first edit. |
| Per-plan build passes, merged build fails | 18-06 turned pipeline stage 7 into a nested `6a.` sub-item under item 6. The list had no blank line after `Pipeline stages:`, so docutils read it as one paragraph and the indent became an unexpected block quote. Each plan's own `sphinx-build` passed; the merged build failed. Fixed in `34497f9`. | advisory | Post-merge gate must run the **docs build** (`sphinx-build -W --keep-going`) in addition to pytest. Pytest alone would have passed this wave green. |
| Semantic figure properties survive file-existence checks | 18-04's generator classified discovery edges into a `frozenset`, discarding direction, then always drew camera→frame. Three of six arrows rendered backwards. Every automated check (grep guards, ruff, sphinx, pytest) passed. | advisory | Direction/ordering properties of generated figures need a human-verify gate or an explicit assertion on the ordered pair — never infer correctness from "the script ran and the file exists". |
| `files_modified` under-declares reality | 18-07 edited `src/aquacal/calibration/intrinsics.py`, which was not in its declared `files_modified`, as a Rule 2 deviation. The intra-wave overlap check that decides parallel-vs-sequential dispatch reads `files_modified`, so an under-declaration can silently permit a conflicting parallel dispatch. | advisory | When an executor reports an out-of-scope edit, re-check it against the other plans in the same wave before merging. Here `intrinsics.py` was unique to 18-07, so no conflict. |
