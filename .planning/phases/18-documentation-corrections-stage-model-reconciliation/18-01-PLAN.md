Correct the four live numeric errors in `docs/guide/optimizer.md`'s sparse-Jacobian section
(DOCS-01) and pin the corrected numbers with a live test so they cannot rot again.

the code — D-20 fixes the cause, not just the symptom.

`tests/unit/test_optim_common.py`, and a corrected numbers section in `docs/guide/optimizer.md`.

DOCS-01 is a pure arithmetic correction, unaffected by however the stage/BFS vocabulary
question resolves. It owns `docs/guide/optimizer.md` in wave 1; later plans that touch the
same file are sequenced into later waves for that reason.
