lockstep with every test that asserts the old literals, and collapse the auxiliary-camera
`Stage 4b` / `Stage 3b` label (DOCS-06, code side).

schema must be settled before the experiment grid runs — settling it afterwards means
re-running the grid. Phases 16-17 are unreleased on local `main`, so this is the last moment
the keys are free to change without breaking a published artifact. Per D-03 there is no compat
shim: a rename that leaves `trace_stage4.csv` sitting beside a `stage3_*` timing key would
recreate exactly the two-vocabularies problem this requirement exists to close.

Output: Renamed keys, tags, filenames, and console strings in `pipeline.py`, with six test
files moved in the same commits.

The critical execution risk here is splitting a literal from its assertion. `pipeline.py` has
no default-valued stage parameters — every stage string is passed explicitly at the call site
— so a rename that misses a test literal turns a green 799-test suite red with no compat
layer to soften it. Source and the tests asserting it move together, task by task.
</objective>
