<objective>
Close the defect the 26-10 smoke pass surfaced twice: `e3` is scheduled at stage 3 but consumes an
artifact that `e2_production` does not write until stage 8, so it dies on
`ValueError: cannot convert float NaN to integer` (`e3_derived_quantities.py:861`) and never writes
`structural_scaling.csv`, `cpr_grouping.tex` or `cpr_derived_values.tex`.

Purpose: this fails the FROZEN run, not just the reduced-scale one. It has been latent for as long as
`experiments/results` happened to still hold a previous run's `benchmark.json`; 26-09's archive-aside
is what exposed it. Left unfixed, stage 3 of a 22-31 hour run crashes, and the abort protocol's
answer to a src defect is restart-from-stage-1 — so the cost is the entire run.
Output: the missing dependency edge, the stage array moved to match, and a tier-3 writer that
records an absent record instead of crashing on it.
</objective>
