<objective>
Close the gap that blocks plan 26-10: the driver has no reduced-scale path, so D-33 form 1 (the
`--smoke` acceptance pass) cannot run at all. All 20 stages invoke their experiments at full scale,
and `--profile smoke` selects only the completeness gate's expectation profile.

Purpose: the dry-run seam substitutes the ENTIRE command, so it proves sequencing, resume, and gate
wiring but can never prove that a stage's invocation line is correct. A typo like `--out` vs
`--output` in one stage passes all 20 dry-run tests and all 113 unit tests, then fails hours into
the frozen run. This plan makes the real invocation lines executable in minutes.
Output: a `SUITE_SMOKE` path in the driver, its tests, and an ignore rule for the smoke out dir.
</objective>
