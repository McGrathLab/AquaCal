<objective>
Make the committed-baseline rails re-aim themselves at `experiments/results` the moment Phase 28
repopulates it, instead of permanently validating the archive they were repointed at.

Purpose: these modules carry the provenance, schema and exhaustiveness gates for the whole
experiment suite. Right now every one of them passes against a frozen archive, so after the frozen
run they would report green while checking nothing about it. This project has been bitten by that
exact shape before (the decision-coverage gate that passed while parsing nothing).
Output: one resolver, used by four modules, with the carve-out explicitly scoped to the archive.
</objective>
