<decision_already_made>
**The algorithm is DECIDED. Do not re-evaluate it.**

RESEARCH.md's main body (§Q2, Open Question 1) presents "direct SVD vs. Gram-matrix eigh" as
an open tradeoff. That is **superseded by the Addendum at the end of RESEARCH.md**, which
settled it by measurement:

| Route | Extra memory | `sigma_min` rel. error | Yields V? |
|---|---|---|---|
| `svd(J, full_matrices=False)` | ~2x J | exact | yes |
| `eigh(J.T @ J)` | ~0 | **1.0 — returns exactly 0.0, cond = inf, correlation all-NaN** | no |
| **blocked tall-skinny QR + `svd(R)`** | **O(chunk·n), independent of m** | 7.2e-8 | yes |

- **Do NOT implement `eigh(J.T @ J)`, not even as a fallback.** It fails in precisely the
  near-degenerate WP6 regime this function exists to measure.
- **Do NOT use `svd(J, compute_uv=False)`** as the primary route: it gives the spectrum but
  no right singular vectors `V`, so it cannot produce the correlation matrix. (It is fine as
  a *reference* inside tests.)
- **Implement blocked tall-skinny QR.**
</decision_already_made>

<oom_trap>
**This exact code path crashed a machine during a previous session. Read carefully.**

`scipy.linalg.qr(J, mode='r')` returns `R` with shape `(m, n)` — NOT `(n, n)`. Only
`mode='economic'` returns the `(n, n)` factor. Feeding a `mode='r'` result into
`scipy.linalg.svd(R)` with its default `full_matrices=True` allocates an **m x m** `U`
matrix: 12.8 GB at m=40000, far worse at the real rig's m.

Mandatory in the implementation:
- every `qr` call uses `mode="economic"`
- every `svd` call uses `full_matrices=False`
- assert the reduced factor's shape is `(n, n)` before the SVD, with an explicit comment
  naming this trap
</oom_trap>

Define:

```python
class ConditioningMemoryError(MemoryError):
    """Raised when conditioning diagnostics would exceed the allowed allocation."""


@dataclass
class ConditioningReport:
    singular_values: NDArray[np.float64]   # (n,), descending
    condition_number: float                # s[0] / s[-1]; math.inf if s[-1] == 0.0
    correlation: NDArray[np.float64]       # (n, n), unit diagonal
    rank: int
    rank_tolerance: float
    n_params: int
    n_residuals: int
    parameter_names: list[str] | None = None


def compute_conditioning(
    jac,
    parameter_names: list[str] | None = None,
    chunk_rows: int = 8192,
    rank_rtol: float = 1e-12,
    max_bytes: int = 2_000_000_000,
) -> ConditioningReport:
```

Algorithm, in this exact order:

1. Read `m, n = jac.shape`. If `m < n`, raise `ValueError` naming both numbers and saying the
   system is underdetermined so conditioning at the solution is undefined.
2. If `parameter_names` is not None and `len(parameter_names) != n`, raise `ValueError`.
3. Analytic memory pre-check (no `psutil`, no probing — the algorithm's transient is
   O(chunk*n) and independent of m, so a cheap closed form is sufficient and no new
   dependency is warranted). Let `block = max(chunk_rows, n)`. Estimate
   `est = (block + n) * n * 8 * 3   # stacked copy + LAPACK workspace + R`
   plus `n * n * 8 * 4   # V, cov, corr, scratch`.
   If `est > max_bytes`, raise `ConditioningMemoryError` whose message names the estimated
   size in GB, the actual `m` and `n`, and the exact config key to turn this off
   (`save_conditioning: false`). Do NOT narrow the metric, do NOT fall back to a cheaper
   route — CONTEXT.md requires refusing loudly instead.
4. Blocked reduction. Start `R = np.zeros((0, n), dtype=np.float64)`. Iterate
   `for start in range(0, m, block)`: slice `jac[start : start + block]`, densify with
   `chunk.toarray()` if it exposes `toarray` (the optimizer falls back to a sparse Jacobian
   above `_optim_common.make_sparse_jacobian_func`'s 500M-element `dense_threshold`), else
   `np.asarray(chunk, dtype=np.float64)`. Then
   `R = scipy.linalg.qr(np.vstack([R, chunk]), mode="economic")[1]`.
   Never hold a reference to the full `jac` beyond the loop.
5. After the loop assert `R.shape == (n, n)` with a comment citing the mode='r' OOM trap
   above; raise `RuntimeError` with the observed shape if it does not hold.
6. `_, s, Vt = scipy.linalg.svd(R, full_matrices=False)`; `V = Vt.T`. `s` is already
   descending. Take `np.abs(s)` (QR can flip signs into R; singular values must be
   non-negative) and re-sort descending.
7. `condition_number = float(s[0] / s[-1])` guarded: if `s[-1] == 0.0` use `math.inf`.
8. Rank truncation and correlation:
   ```python
   tol = rank_rtol * s[0]
   keep = s > tol
   rank = int(keep.sum())
   Vk = V[:, keep]
   cov = (Vk / s[keep] ** 2) @ Vk.T          # V diag(1/s^2) V^T
   d = np.sqrt(np.diag(cov))
   corr = cov / np.outer(d, d)
   np.fill_diagonal(corr, 1.0)
   corr = np.clip(corr, -1.0, 1.0)
   ```
   If `rank == 0`, raise `ValueError` (degenerate Jacobian, nothing to report).
9. Return the populated `ConditioningReport` with `n_residuals=m`, `n_params=n`,
   `rank_tolerance=float(tol)`.

Google-style docstrings with array shapes, `numpy.typing.NDArray` hints, imports grouped
stdlib / third-party / local per `.claude/rules/code-style.md`.

Tests in `tests/unit/test_conditioning.py`:
