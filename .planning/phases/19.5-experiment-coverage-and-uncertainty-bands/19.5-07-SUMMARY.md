# Phase 19.5 Plan 07: COV-07 E2 Seed-Variant Config Generator Summary

Pure config-generator and calibration-free CLI path for E2's calibration/holdout
split-variance band -- no calibration run, code and tests only.

## What Was Built

`experiments/e2_real_rig.py` gained two new functions and a new CLI path:

- `build_seed_variant_config(source_text, seed, output_dir) -> str` -- a pure
  text-to-text transform. Finds and replaces a top-level `seed:` line, or inserts
  one (immediately before the top-level `paths:` block, or at EOF if there is no
  `paths:` block) if absent. Finds the `output_dir:` line scoped to inside the
  `paths:` block (by indentation and block-boundary scanning, not a bare string
  search) and replaces its value with a JSON-quoted (i.e. valid double-quoted
  YAML) string. Every other line -- comments, blank lines, key order, camera
  lists, every video path -- is untouched, verified by an exact line-for-line
  diff assertion in the tests, not by eyeballing a string.
- `emit_seed_variant_configs(source_path, seeds, band_dir) -> list[Path]` --
  writes `band_dir / config_seed{seed}.yaml` per seed with `output_dir` set to
  `band_dir / seed_{seed}` (posix-style). Raises `ValueError` if `band_dir`
  resolves to or inside `source_path.parent`.
- CLI: `--emit-band-configs` (store_true), `--band-seeds` (comma-separated,
  default `"42,43,44"`, parsed via `experiments._io.parse_seed_list`),
  `--band-dir` (`Path`). `_validate_e2_args` rejects `--emit-band-configs`
  combined with `--check`/`--smoke`, and requires both `--config` and
  `--band-dir` when `--emit-band-configs` is given. `_run_emit_band_configs`
  writes the variants plus `band_dir/e2_band_scope.json` (`source_config`,
  `source_config_sha256`, `seeds`, `n`, and a `scope` field containing both the
  phrase "split variance" and "NOT measurement variance" per D-19.5-05) and
  returns 0 before any calibration branch (`_run_smoke`/`_run_check`/`_run_full`)
  is reached. The shared five-flag set (`--check --force --out --seed --smoke`)
  is unchanged.

`tests/unit/test_e2_split_band.py` (19 tests, all passing, ~0.9s) covers: the
exact two-key diff for a fixture with comments/blank lines/nested `paths:`
block; seed insertion (no prior `seed:` key, gains exactly one line,
`yaml.safe_load` roundtrips correctly); seed replacement (prior `seed: 42`,
net-zero line change); every source comment line surviving into the output;
three emitted variants differing from one another only in `seed`/`output_dir`
lines; the release-tree write refusal (both `band_dir == source parent` and
`band_dir` nested inside it); the CLI `--help` text, the four validation error
paths, the shared five-flag contract, and the full `--emit-band-configs` run
(three files + scope JSON written, `run_calibration` never referenced in
`_run_emit_band_configs`'s own source, scope text asserted, default seed list
asserted, and the emitted variant parses with the right `seed`/`output_dir`).

## Command for Plan 09's Queue Stage

Emit the three variants (default seed list `42,43,44`):

```bash
python -m experiments.e2_real_rig \
  --emit-band-configs \
  --config "C:/Users/tucke/Desktop/Aqua/AquaCal/release_calibration/config.yaml" \
  --band-dir "C:/Users/tucke/Desktop/Aqua/AquaCal/e2_band"
```

This writes `e2_band/config_seed42.yaml`, `config_seed43.yaml`,
`config_seed44.yaml`, and `e2_band/e2_band_scope.json`. No calibration runs.

One band run's `--config` invocation (repeat per seed, `--out` per seed):

```bash
python -u -m experiments.e2_real_rig \
  --config "C:/Users/tucke/Desktop/Aqua/AquaCal/e2_band/config_seed43.yaml" \
  --out "C:/Users/tucke/Desktop/Aqua/AquaCal/e2_band/seed_43_e2_out" \
  --force
```

Each variant's own `paths.output_dir` (`.../e2_band/seed_{seed}`) is where the
pipeline itself writes `calibration.json`/`benchmark.json`/
`spatial_measurements.csv`; `--out` is where E2's own CSVs/metrics land. This
is a 48-87 minute calibration per seed -- run it in plan 10's queue, never here.
