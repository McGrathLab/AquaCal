# Phase 19.5 Plan 08: E4 Repeat Splice Helper Summary

**Pure-function splice of two E4 runs into a defensible n=2 timing spread, plus a no-solve `--splice-repeat` CLI path writing `benchmark_grid_repeat.csv`.**

## Performance

- **Duration:** ~35 min
- **Completed:** 2026-08-06T08:00:29-04:00
- **Tasks:** 2 completed (committed together, see Deviations)
- **Files modified:** 2

## Accomplishments
- `REPEAT_CELLS = [(8, 100), (12, 100), (16, 100)]` declared with both load-bearing reasons in-line (MF-03's evidence; the 200-frame cells' memory ceiling).
- `splice_repeat_records(frames, cells)` — a pure `DataFrame`-in/`DataFrame`-out function: labels each run with a 1-based `repeat` column, refuses on a partial cell set, a null `nfev` beside a non-null wall-clock figure, or disagreement on `n_observations`/`normal_fixed`/`shared_interface`/`seed` across runs. Adds `seconds_total` (null-safe sum) and `seconds_total_spread_pct` (`(max-min)/mean*100` per cell, n=2 only — no p-value, no interval).
- `--splice-repeat <repeat_out_dir>` CLI flag: loads the committed `benchmark_grid.csv` as run 1, aggregates `<repeat_out_dir>/e4_cells/` as run 2 via the existing `aggregate()`/`_extract_assembled_row` path, splices, and writes `benchmark_grid_repeat.csv` (key columns `n_cameras`, `n_frames`, `repeat`) with a `scope` column stating what the repeat bounds (D-19.5-05). Prints each cell's `seconds_total_spread_pct` to stdout for the queue log. Mutually exclusive with `--check`/`--smoke`, enforced in `_validate_e4_args`. Dispatched in `main()` before any solving branch.
- 20 new tests in `tests/unit/test_experiments_e4.py` (`TestSpliceRepeatRecords`, `TestSpliceRepeatCli`) covering every acceptance criterion: six-row splice with repeat labels, missing-cell refusal, null-nfev refusal, identity-disagreement refusal, exact spread-pct value on known totals, no p-value/interval column, no file opened inside the pure function, `--help` lists the flag, `--splice-repeat` + `--check`/`--smoke` both name both flags, the shared five-flag contract is unchanged, an end-to-end CLI drive against a synthetic `e4_cells/` tree writing a six-row CSV with `calibrate_synthetic` monkeypatched to raise if called, and a `git status --porcelain experiments/results/` emptiness check.

## Decisions Made
- `seconds_total_spread_pct` is defined as `(max - min) / mean * 100` over the cell's `seconds_total` values (n=2), matching "the run-to-run spread as a percentage of the cell's mean" from the plan text.
- The CLI's `--splice-repeat` write always uses `force=True` (like the existing `_run_band`-style band CSVs) since regenerating the splice each queue run is the point, not a resumability target.
- `benchmark_grid_repeat.csv` is deliberately NOT added to `CSV_TO_RECORD` in `tests/unit/test_experiments_provenance.py` in this plan — see key-decisions above and Deviations.
