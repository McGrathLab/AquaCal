<design_decision>
**Do NOT widen `CPR_CONFIGS`.** `cpr_grouping.csv` and `cpr_grouping.tex` are committed baseline
artifacts that E3's `--check` compares against and that the manuscript's supplement table renders
from. Widening the config list changes both and breaks `--check`. COV-01 therefore lands as a
**separate tier** writing a **separate artifact**, leaving every existing E3 output byte-identical.

**Locate the 500 M boundary analytically, not by trial.** Building a real `(n_residuals, n_params)`
int8 array at, say, 64 cameras × 200 frames is ~2.4 GB — the sweep would OOM before it reached the
boundary. Build the real sparsity only where `n_residuals * n_params <= 200_000_000`; beyond that,
use a closed-form shape predictor that has been proven to agree with the real array everywhere it
was affordable to check.
</design_decision>
