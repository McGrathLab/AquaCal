## Traps found and fixed this session — do not reintroduce

- **A dry run used to write the REAL state file.** Automatic resume skips any stage with a
  completion line, and a dry run "completes" all five in ~1 s, so the next real launch would
  have skipped everything and exited 0 with no artifacts. Dry runs now write
  `rerun_19_5_state.dryrun.tsv` (gitignored). If you dry-run to sanity-check control flow,
  confirm afterwards that `experiments/rerun_19_5_state.tsv` does **not** exist.
- **The gate kept its own hardcoded seed list**, which could silently diverge from the
  queue's. It now reads `E6/E5_BAND_SEEDS` from `rerun_19_5.sh`.
- **ARCHIVES_PRESENT used to FAIL by design** and plan 09 documented it as expected-and-benign.
  It now returns **N/A**, but only when it can prove the premise absent (SUMMARY declares it
  AND no 19.5 commit touched `src/`). A phase that moved `src/` and lost its archives still
  FAILs. Do not re-add a "known benign FAIL" — that was the thing being removed.
- **Provenance gap inherited from 19.4**: `exp1_band.csv` and `interface_ablation_band.csv`
  were unregistered since 19.4 closed and no suite had run since. Fixed, plus a new
  class-closing gate. The E1/E7 sidecars are `SEEDLESS_LEGACY_RECORDS` carrying **no seed key
  at all** — they do not cover those bands, and no entry should imply they do.

## During the run — binding

- **Commit nothing between launch and completion.** A mid-run commit splits the recorded sha.
- **Never edit `src/` or `experiments/` mid-run.** A src defect ⇒ abort and restart from
  stage 1. `bash experiments/rerun_19_5.sh N` resume is for INFRASTRUCTURE failures only.
- **Exit codes are not evidence.** E4/E6 record failures as rows and still exit 0. Read the
  per-seed `status` counts out of the CSVs.
- **A quiet log is not a dead run** — but note Git Bash `ps` cannot see Windows processes.
  Use PowerShell `Get-Process python` to check. This bit me once this session.
- Keep the machine otherwise idle during `e4_repeat`: the 16-camera cell will **page, not
  OOM** (Windows), and both repeats of a cell run back-to-back specifically so the measured
  `seconds_total_spread_pct` is not a paging artifact.
