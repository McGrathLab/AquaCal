<objective>
Wire the `shared_interface` flag from config into the Stage 3 (`optimize_interface`) and Stage 4
(`joint_refinement`) optimizers so per-camera water_z reaches the solver, and emit the single
ablation WARNING at pipeline start. Each optimizer gains a `shared_interface: bool = True` parameter
and passes it to every `_optim_common` function it calls plus `build_parameter_labels`; in per-camera
mode it seeds each camera's water_z from the per-camera dict INDIVIDUALLY (never collapsed to the
reference camera's value or a mean).

Purpose: connect plan 17-01's per-camera machinery to the live pipeline behind plan 17-02's config
flag, and announce the mode once, loudly, with the reason. This is the integration layer.
Output: shared_interface-threaded optimizers + pipeline wiring + the IFACE-01 WARNING, with unit
tests that the optimizers run and round-trip per-camera water_z end to end.
</objective>
