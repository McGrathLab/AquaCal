`OptimizerObserver.on_solution(result)` is the precedent for "read scalar fields from `result`
immediately after `least_squares` returns, never retain `result` itself." Note `OptimizerObserver`
is NOT exported from `aquacal.calibration.__init__` — it is imported directly from
`aquacal.calibration._observability` by `pipeline.py` and the four optimizer modules. This
plan's `SolverDiagnostics` follows the same precedent and must NOT be added to
`aquacal/calibration/__init__.py`'s `__all__` — it is a private-module helper type used only
in trailing keyword parameters of exported functions, exactly like `OptimizerObserver`.
