<objective>
Wire everything Plans 19-01 through 19-04 built into `run_calibration_from_config`: thread
`diagnostics_out=SolverDiagnostics()` through the pipeline's four `least_squares`-backed call
sites, add the two opt-in config flags (`save_benchmark`, `benchmark_memory`), and implement
`assemble_benchmark_record()`/`write_benchmark_json()` in `io/benchmark.py` to produce
`output_dir/benchmark.json` — problem shape, per-stage solver diagnostics, P/group-count/FD
reduction, solver configuration in force, accuracy copied from the already-computed
`DiagnosticsData`, environment, and (opt-in) peak memory. This is the phase's central
integration plan (BENCH-03, BENCH-04) and depends on every prior plan's contract.

Purpose: BENCH-04 requires a machine-readable performance record per run, for real-rig and
synthetic runs alike, that a downstream sweep (BENCH-05, Plan 19-06) can aggregate without
recomputing anything. D-04's `schema_version` and D-05's never-fails environment capture make
this record trustworthy across a multi-day sweep spanning code changes.
Output: `output_dir/benchmark.json` written by every `run_calibration_from_config` call when
`config.save_benchmark` (default `True`) is set.
</objective>
